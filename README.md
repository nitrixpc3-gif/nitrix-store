# NITRIX PC Store — PC Builder V1

افتح `index.html` لتجربة الموقع، أو افتح `pc-builder.html` مباشرةً لتجربة أداة بناء التجميعة.

## ما تمت إضافته
- PC Builder ثنائي اللغة عربي/إنكليزي.
- اختيار Intel أو AMD.
- 28 خياراً تجريبياً من المعالجات والمذربوردات وكروت الشاشة والرام والتخزين والباور والكيسات والتبريد.
- فلترة تلقائية للمذربورد حسب سوكت المعالج.
- فحص توافق السوكت، نوع الذاكرة، قدرة مزود الطاقة، حجم المذربورد والكيس، ودعم المبرد.
- حساب السعر واستهلاك الطاقة والقدرة المقترحة للباور.
- حفظ التجميعة ونسخ مواصفاتها وإرسالها إلى واتساب NITRIX.

## ملاحظات قبل الإطلاق
- الأسعار الموجودة لقطة مرجعية من الأسعار المنشورة على موقع العالمية وقت إعداد النسخة، وليست مزامنة تلقائية.
- يجب تثبيت مخزون NITRIX وسعر البيع النهائي من لوحة الإدارة لاحقاً.
- صور المنتجات مستخدمة داخل النموذج التجريبي لتسريع التطوير. قبل الإطلاق التجاري استبدلها بصور الشركات المصنّعة أو صور المورد المصرح باستخدامها أو صور مخزون NITRIX.
- أوصاف المنتجات داخل المشروع مكتوبة بصياغة NITRIX وليست نسخاً مباشراً من متجر آخر.
